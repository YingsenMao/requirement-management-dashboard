User Training Guide

Why This Platform?

The Problem

Managing requirements from global users manually is chaotic, time-consuming, and lacks objective prioritization.

The Solution

A centralized platform that enables Product Managers to collect, manage, and prioritize feature requests with automated scoring.

Key Benefits

  • Transparency: All users can see requirements and their status
  • Efficiency: Automated workflows reduce manual overhead
  • Objectivity: Priority scoring based on ROI and risk factors
  • Security: Department-scoped access control

What Can It Do?

🔐 Role-Based Access

Admin vs Regular User roles with distinct permissions

🏢 Department Scoping

IT and R&D departments with isolated data access

🔄 State Machine

Request lifecycle with automatic locking after assessment

📊 Auto Priority Scoring

Weighted algorithm calculates priority based on multiple factors

🤖 AI-Powered Review

AI assists IT requirements with up to 5 follow-up questions

📎 Secure Attachments

Upload up to 3 files with size and type validation

Regular User Workflow

  1. Login → Access the platform with your credentials
  2. Create Requirement → Select department (IT or R&D) first, then fill in details
  3. Add Attachments → Upload up to 3 supporting documents (PDF, DOCX, XLSX, PNG, JPG, max 5MB each)
  4. AI Review (IT Only) → Optional: Let AI ask up to 5 questions to refine your requirement
  5. Submit & Track → View your requirement in the global list, sorted by priority score
  6. Edit (If Needed) → Edit your own requests only when status is "Pending Review" or "Rejected"
  7. Lock After Assessment → Once admin assesses, the request becomes read-only

Note: You can view all requirements but can only edit your own. Other users' requirements are read-only.

Admin Workflow

  1. Login → Access with department-assigned credentials (IT or R&D)
  2. View Requirements → See only requirements from your department (department-scoped list)
  3. Assess Requirement → Click "Assess" to set:
    • Workload (Small / Medium / Large)
    • Status (Pending Review → Under Review → Confirmed → In Development → Completed, or Rejected)
    • Estimated Completion Date (optional)
  4. Auto Priority Score → System automatically calculates priority score based on your workload input
  5. View AI History (IT) → For IT requirements, view the full AI review conversation if applicable
  6. Manage Users → Create new user accounts (Regular User or Admin with department)

Important: You cannot edit the user's original content or change the owning department. You can only set workload, status, and estimated completion date.
